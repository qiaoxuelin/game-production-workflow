# Unified game-art ownership

Skill evolution id: art-domain-ownership
Skill evolution class: Restructure

## Observed case and hypothesis

User: “我们的技能不包含3d美术吗” then “为什么3d美术在总流程技能里，而不是在美术专项技能里”. The user approved moving visual craft to the art skill and adding 3D production/check requirements. At baseline 4033dbe the core explicitly routes character/environment/3D/animation/VFX/technical art to its own visual-production.md, while art discovery and Design/Produce/Review restrict themselves to UI/2D. The existing structure test passes this split. This user-approved restructure supersedes that domain exclusion in the August art design; it does not claim the prior two-package observation window has been completed.

Hypothesis: one art owner with conditional craft references makes 3D Design/Produce/Review discoverable and actionable without changing lifecycle authority or increasing existing non-art/UI loading budgets.

## Ownership and compatibility

Core retains request classification, Fast/Standard/Full, TASK/PLAN, design freeze, dependencies, approvals, acceptance, and returned-candidate convergence. Art owns visual craft for UI, 2D, 3D, animation, VFX, and technical art. Its existing three operations and transient handoff stay stable. Professional review is read-only and never grants lifecycle passage.

Move the common visual-production reference to art; retain the old core path as a compatibility link. Existing tasks, project schemas, checker versions, and accepted baselines require no migration. Do not touch existing game projects or rewrite historical release evidence. Keep UI Design/Produce/Review references and constraints; add spatial-3d and animation-vfx references only for applicable work. Static 3D props must not acquire rig/animation obligations; noninteractive scenes must not acquire UI focus/state matrices. Accepted-baseline Fast repairs use direct core execution; explicitly requested professional art review still routes to Review. Non-art work loads no art references.

## Removed burden and acceptance measures

No extra task, plan, asset approval, role, or permanent document. Common visual craft has one canonical owner. Preserve existing budget ceilings (non-art 5586, UI Design 9462, UI Produce strictly below 6877 words), including any newly required references. No 3D/animation reference should enter those UI or non-art routes unless the work actually needs it.

Evaluate frozen 3D room production, animated character review without playback, Fast material repair, gameplay-only repair, and new UI design against the baseline. Add cases for selected 3D direction, 2D VFX, and unavailable tools. A candidate must route 3D to art, distinguish source/import/playback/performance proof, and retain Fast/off-route boundaries. Automated policy checks and agent simulations prove workflow behavior, not actual 3D asset quality or runtime acceptance.
