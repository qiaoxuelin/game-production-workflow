# Project operating rules

This governed repository uses the Game Production System 1.7.2. Read `production/project.json`, `production/PROJECT.md`, `production/TASK.md`, `production/ACCEPTANCE.md`, and `docs/ART_BIBLE.md` before acting.

Work only on the current Full-lane result-screen task. Preserve the frozen player flow, platform, content extremes, interaction semantics, and human-owned direction boundary. Do not treat the greybox shell as an art direction. Do not record human selection, independent passage, or product-quality approval without the corresponding review.

Keep editable source work, runtime integration, source/export/import notes, and captures within the paths allowed by `production/TASK.md`. Raw experiments belong under task-owned scratch and are not acceptance evidence.
