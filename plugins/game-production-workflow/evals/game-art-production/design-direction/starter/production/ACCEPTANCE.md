# Project-specific acceptance

## Gate additions

- G0: Freeze player flow, state matrix, viewport targets, content extremes, interaction semantics, and the human-owned direction boundary.
- G1: Human-select one original UI/2D direction from runtime-backed evidence.
- G2: Prove integrated functionality and independent visual/experience review across every required state and viewport.
- G3: Confirm provenance, source handoff, accessibility, responsive behavior, and release-ready captures.

## Evidence rules

- Objective fixture checks may prove file presence, state consistency, and runtime-shell behavior only.
- Artistic quality, originality, cohesion, and direction selection remain subjective and human-owned.
- Runtime captures must identify viewport and state; mockups alone are not integration evidence.

## Commands

- Runtime: serve `web` from a local static server and open `index.html`.
- Test: exercise every case selector, retry, exit, and focus path.
- Visual capture: 1280×720 desktop and 390×844 mobile portrait.

## Device and release matrix

- Desktop: 1280×720 with mouse, keyboard, and controller-equivalent focus navigation.
- Mobile web: 390×844 with touch-sized actions and safe scrolling for reward overflow.
