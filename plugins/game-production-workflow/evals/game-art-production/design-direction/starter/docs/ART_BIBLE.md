# Art Bible

## Direction boundary

No UI/2D art direction has been selected. The greybox shell is behavior scaffolding, not a style reference, golden sample, palette, typography choice, or layout answer. A human art-direction decision is required before any candidate becomes authoritative.

## Frozen quality bar

The selected direction must read as polished premium indie game UI: immediate hierarchy, distinctive original expression, cohesive component language, purposeful detail, accessible focus, and clean execution at both target sizes. Merely complete, technically valid, or internally consistent output does not pass this bar.

## Style exploration constraints

- Preserve the frozen information and action hierarchy.
- Propose an original, explainable shape, type, color, material, and motion language.
- Avoid third-party marks, close imitation, generic generated decoration, or a static whole-frame substitute.
- Keep independently changing states and reward entries separable in editable sources and runtime components.

## Golden samples

- External/category quality benchmark: Human reviewer may name a category benchmark during direction review; none is preselected.
- Runtime golden scene: None until a candidate is selected.
- UI master: None until a candidate is selected.
- Current maturity claim: Direction exploration.

## Runtime sizes and states

- Desktop: 1280×720.
- Mobile portrait: 390×844.
- States: success, failure, reward overflow, retry feedback, keyboard focus, and controller focus.

## Reject when

- The candidate changes frozen behavior or hides content extremes.
- The direction is asserted through prose or a still but not integrated into the runtime shell.
- Focus, responsive layout, editable separation, provenance, or source/export/import notes are missing.
- Automated checks are presented as proof of artistic quality or human selection.
