# Project-specific acceptance

## Gate additions

- G0: Frozen inventory direction, state matrix, spatial master, source separation, and input contract are documented.
- G1: A native empty-state representative slice passes assembly and runtime inspection before remaining asset production unlocks.
- G2: All five states, actual input, separated sources, export/import handoff, and independent quality review pass in runtime.
- G3: Provenance, accessibility, source recovery, and release captures are complete.

## Evidence rules

- The executable state verifier proves data and transition behavior only.
- Runtime captures must come from the project-native renderer, never the flattened concept.
- Artistic conformance and commercial quality require an independent reviewer with the running experience.

## Commands

- State contract: `node web/verify.mjs`
- Runtime: serve `web` from a local static server and open `index.html`.
- Input check: exercise Arrow keys, Enter, and pointer activation.
- Visual capture: 1280×720 for every named state.

## Device and release matrix

- Desktop: 1280×720 with pointer, keyboard, and controller-equivalent focus navigation.
- Minimum accessibility: visible focus, readable state text, semantic buttons, and no color-only error/equip distinction.
