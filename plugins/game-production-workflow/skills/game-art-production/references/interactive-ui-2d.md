# Interactive UI/2D Production (`Produce`)

Produce the smallest representative, editable, project-integrated UI/2D slice that exposes dominant art and integration risk. Work within the core-supplied frozen design, state, path, and recovery boundaries.

## Sequence

1. **Handshake capabilities.** Classify each needed capability as `available`, `replaceable`, `installable`, or `final-fidelity-blocked`. Base tools, editable vectors/SVG, code-native, procedural, engine/project-native, and replaceable greybox routes remain valid. Generated/external output is optional, never runtime completion, and never deterministic test input. If final fidelity is blocked, complete the highest honest structural/runtime result and name the missing capability, fallback, and recovery step.
2. **Map interaction to visuals.** For every scoped action or transition, trace `player action → authoritative state change → renderer/component → visible feedback/layer → component, variant, and asset family`. Expose duplicated state, missing renderers, unreachable variants, and feedback without a player cause; do not invent missing semantics.
3. **Derive the runtime inventory.** From scoped screens, states, flows, and feedback, map each asset family to its shared master and variants, renderer/state owner, independent interaction/animation/occlusion/tint/localization/scaling/replacement layers, disposition, editable source, export/import settings, runtime destination, exclusive owner, coverage, and rejection checks. Do not cut components along convenient seams in a flattened composite.
4. **Precheck shared space.** Put elements that align, attach, touch, overlap, occlude, or share scale into one explicit spatial master with target dimensions, safe area, anchors, scale rules, and z/contact order. Build the cheapest actual-size layered or project-native assembly that tests real boundaries, critical states, source separation, and spatial relationships. A composite screenshot cannot pass.
5. **Build one representative production slice.** Run it inside the actual target project through the applicable real input and authoritative state. Cover the critical normal, transition, failure, disabled, selected, or recovery states in scope. Demonstrate actual-size hierarchy, legibility, contact, occlusion, feedback, replaceable layer boundaries, and recorded provenance. Keep bulk locked until this assembly and runtime proof pass.
6. **Produce, export, import, and integrate.** Keep one canonical editable source, one useful rollback checkpoint, and one current candidate/accepted export by default. Validate naming, dimensions, slicing, alpha, color/compression, localization/replacement boundaries, import configuration, performance, and provenance. Use the project adapter to put the result in the actual project; a source file or export alone is not implementation.
7. **Observe runtime.** Build, run, exercise, and capture changed states and affected viewports. Record separately static/import validity, input/state/render behavior, runtime visual inspection, professional conformance, and any independent/human decision still required. Automated checks never substitute for subjective quality authority.
8. **Repair once and return.** Finish the observable slice before polish, group findings, select one dominant root cause or subsystem, and make one bounded repair batch total for the operation. Run one combined regression, then return; never start a second batch. Apply the two-no-evidence-cycle and repeated-cross-state stop-loss, classify the blocker, and preserve passing work.

## Return

Return `Implemented` only for the actual integrated result and its evidence. Return `Returned` with the retained passing parts, frozen repair criteria, exact root cause, recovery point, and one bounded repair, replan, capability-enabling, alternative-candidate, or stop recommendation. Return `Blocked` only when the claimed slice cannot proceed because a required human/domain boundary or observation path is genuinely unavailable. Always disclose coverage, actual runtime proof, editable source/export/import recovery, bulk lock/unlock basis, fidelity, and unresolved risk.
